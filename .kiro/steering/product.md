# Product Overview

Sands is an AI-powered interactive murder mystery game that generates unique closed-circle detective stories for players to solve.

## Core Concept
- Players take on the role of a detective solving randomly generated murder mysteries
- Each case features unique suspects, motives, opportunities, and means
- Classic closed-circle mystery format with limited suspects (2-10 per case)
- Choose-your-own-adventure style investigation through chat interface

## Key Features
- **AI-Generated Content**: Dynamic story generation using OpenAI GPT-4
- **Interactive Gameplay**: Real-time chat interface with streaming AI responses
- **Multiple Settings**: Country House, Boat, Aircraft, Island, Cabin, Train
- **User Authentication**: Secure sign-in required via Clerk
- **Responsive Design**: Modern UI optimized for all devices

## Game Flow
1. User authenticates and types "start" to begin
2. AI prompts for setting and suspect count selection
3. Dynamic mystery generation with embedded clues
4. Interactive investigation through natural language chat
5. Player deduces solution based on collected evidence

## Target Audience
Detective fiction enthusiasts who enjoy interactive storytelling and puzzle-solving experiences.
